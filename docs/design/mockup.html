CONCEPT

「幾何学」と「ノート」のあいだ。

  • 幾何学のかっこよさ1px の線・番号・点で組み立てる。余白にはストロークアイコン。英字は Space Grotesk、メタは JetBrains Mono。
  • ノートの自然さ暖色の紙、赤いマージン線、ドットリーダー、明朝の見出し。読む姿勢を妨げない静けさ。
  • グラデーション「藍 → 朱」の1種のみ。1ビュー3箇所まで（1語＋マーク＋タイル1つ）。面積は最小に。
  • ガラスの立体感半透明＋backdrop-filter の「浮遊要素」だけに使う。背景にパターンか色がある場所で限定。

USAGE NOTES

  • GRADIENT「藍→朱」1種。1ビュー3箇所まで（ヒーローの1語＋ロゴマーク＋幾何タイル1つ）。合計面積を最小に保つ。
  • GEOMETRY幾何要素は 1px の線・点・番号に限定。余白の幾何学領域には 1.5px ストロークの SVG アイコン（terminal / code / pen）を配置。シャドウは原則使わない。
  • NOTEBOOK赤マージン線（本文ブロック左）・ドットリーダー（プロフィール）・破線（記事リスト区切り）で「紙」を示す。
  • TYPE ROLES明朝＝見出し / ゴシック＝本文 / Mono＝メタ情報 / Space Grotesk＝英字ロゴ。役割を混ぜない。
  • MOTIONIntersectionObserver ＋ CSS のみ（JS 約15行・ライブラリなし）。fade ＋ 16px 上昇、stagger 70ms、セクション罫線は左から伸びる。prefers-reduced-motion で全無効。
  • GLASSガラスは「背景にパターンや色がある場所」の浮遊要素にのみ使う（ヘッダー / 幾何タイル / カード）。blur 6–10px・背景62%・白ヘアリン罫。ヘッダーは sticky でスクロール時に実物確認。prefers-reduced-transparency では不透明に戻す。
  • DEPTH重なり＋ガラスで立体感。カード＝ガラス面＋フラットな6pxオフセットシャドウ（積み紙）＋ホバーで浮上、セクション番号＝罫線に跨るタブ、幾何学パターンは本文の背面に回り込む。
  • RESPONSIVE860px 以下は1カラムに崩し、幾何装飾（一部タイル・弧）は間引く。
